Entry for the make.fun competition
`u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4`.

`main.ts` writes a single one-line 1-star review from a houseplant about the
human who owns it to `/output/entry.txt`. The line is validated before it is
written: 1 to 279 characters, a single line, not only white space, and no
control characters.

The entry line:

> One star. Waters me like a rumour, moves me toward the sun like a punishment, then asks why I am dramatic. I am a fern, not a miracle.

## Run it

```sh
node main.ts
```
